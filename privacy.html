개인정보 처리방침

앱 이름: 붇다의 범어교실 · 패키지: com.sambyakku.app · 시행일: 2026-08-15

1. 수집하는 정보

이 앱은 계정을 만들지 않습니다. 이름·이메일·전화번호 등 식별 정보를 받지 않습니다.

학습 기록(본 글자, 퀴즈 정오, 쓰기 점수, 공덕·연속일, 즐겨찾기, 손글씨 글자 모양, 화면 설정)은 이 기기에만 저장됩니다. 개발자에게 자동으로 전송되지 않습니다.

2. 인터넷으로 오가는 정보

인터넷은 학습 자료(획 순서, 이론 팁, 한글 힌트, 글자 메모)와 운영 안내(팝업)를 불러올 때 씁니다. 광고·분석·추적 SDK는 넣지 않았습니다.

학습 자료는 GitHub 저장소에서 받습니다. 비공개 자료를 읽기 위해 앱에 읽기 전용 토큰이 들어 있습니다. 이 토큰은 이용자를 식별하지 않으며, 이용자 학습 기록을 올리지 않습니다. GitHub는 접속 과정에서 IP 등 기술 정보를 처리할 수 있습니다. GitHub 처리방침은 GitHub Privacy Statement를 따릅니다.

운영 안내는 공개 안내 파일만 읽습니다. 계정 로그인 없이 받습니다.

3. 권한

  • 인터넷: 학습 자료·운영 안내 받기
  • 진동: 탭·쓰기 피드백

4. 보관과 삭제

기기 데이터를 지우려면 앱을 삭제하거나 기기 설정에서 앱 저장공간을 지우면 됩니다. 서버에 이용자 계정이 없으므로 별도의 계정 삭제 절차는 없습니다.

5. 제3자 제공

학습 기록을 판매하거나 광고에 쓰지 않습니다. 위에 적은 GitHub 학습 자료·안내 받기 외에 제3자에게 개인정보를 제공하지 않습니다.
